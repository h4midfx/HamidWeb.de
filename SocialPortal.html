اطلاعات اتصال خودت

در بخش «ذخیره و بررسی اطلاعات اتصال»، توکن و شناسهٔ حساب خودت را وارد کن. سرور دسترسی را بررسی می‌کند و توکن را رمزگذاری‌شده ذخیره می‌کند.

  • تلگرام: توکن ربات خودت و نام کانال؛ ربات باید مدیر کانال باشد.
  • فیسبوک: توکن مخصوص صفحه و شناسهٔ همان صفحه.
  • اینستاگرام: توکن و شناسهٔ صفحهٔ فیسبوک متصل به حساب حرفه‌ای اینستاگرام.
  • کانال واتس‌اپ: هنوز پشتیبانی نمی‌شود.

ورود مستقیم با حساب اجتماعی و نشر خودکار هنوز پیاده‌سازی نشده‌اند. برای بررسی دوباره، سرور از توکن ذخیره‌شده استفاده می‌کند؛ نیازی به نوشتن دوباره نیست.

این بخش برای توکن API است، نه رمز ورود شبکهٔ اجتماعی. توکن فقط به سرور سایت و API رسمی همان شبکه فرستاده می‌شود. پس از ذخیره، دوباره در صفحه نمایش داده نمی‌شود.

توکن ربات خودت را از BotFather بگیر و ربات را مدیر کانالت بساز. این توکن رمز حساب تلگرام تو نیست.

    ۰۳ / مراحل بعدی

    برای فعال‌سازی چه نیاز است؟

    1. کانال تلگرام و ربات

      ربات به کانال اضافه شود تا سرور بتواند پست‌های جدید را دریافت کند.

    2. اتصال حساب‌های مقصد

      اجازهٔ نشر فیسبوک و اینستاگرام از راه ورود رسمی حساب‌ها دریافت شود.

    3. سرور همیشه‌روشن با HTTPS

      برای دریافت پست‌ها، نگهداری امن دسترسی‌ها و پیگیری نتیجهٔ هر نشر.

    4. بررسی نوع پست

      اگر مقصد از متن، عکس یا ویدیو پشتیبانی نکند، نشر آن مقصد متوقف شود؛ محتوا خودکار تغییر نکند.
